# Synthesis contract

Synthesis is hierarchical because raw swarm output is too large and too correlated to hand to one final model unfiltered.

Six challenge/chair domains:

- product/domain
- execution
- state
- interfaces
- quality
- evolution

Three independent system syntheses then emphasize:

- correctness/failure safety
- ownership/simplicity/boundaries
- evolution/change locality/agent legibility

The final arbiter may resolve wording, priority, grouping, and disputes. It may not invent new findings or evidence.

Final package should include:

1. Executive verdict
2. Reconstructed architecture
3. Intended-vs-actual drift
4. Concept authority matrix
5. Package/dependency observations
6. State and lifecycle map
7. Confirmed findings
8. Disputed findings
9. Defended architecture / rejected hypotheses
10. Accepted debt
11. Failure-scenario results
12. Change-surface results
13. Documentation drift
14. Ordered refactor waves
15. Fitness-function candidates
16. Evidence/provenance appendix

Explicitly answer both:

- What would we keep exactly as it is if rebuilding UltraPlan today?
- Which decisions now cost enough to justify change?
