# Review lenses

The CLI materializes two independent reviewers for each lens.

1. Module ownership and authority
2. Go package dependency graph
3. Study lifecycle
4. Project catalogue
5. Sprint state machine
6. Execute-review-smoke
7. Runcontrol
8. Productstate
9. Operational vs product state
10. App composition/use cases
11. CLI/TUI/web parity
12. Web lifecycle and SSE
13. Runtime/agentwrap/OpenCode
14. Process/smoke harness
15. Filesystem/artifact persistence
16. Configuration/model selection
17. Errors/retry/idempotency/recovery
18. Observability
19. Concurrency/resources
20. Test architecture
21. Security/trust boundaries
22. Agent architecture
23. Simplicity and earned complexity
24. Evolution/change locality

For every lens, trace concepts beyond the first package in which they appear. The unit of review is architectural responsibility, not file size.
